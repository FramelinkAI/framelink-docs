## Let your agent set it up

The easiest way to get started is to let your agent set it up. Copy and paste the prompt below to your active agent and get started.

<Prompt description="Paste this into your coding agent and it will walk you through setup.">
Set up the Framelink Figma MCP server for me. Work through these steps in order and stop where I need to act.

1. Open https://www.figma.com in a browser. If Figma asks for credentials, stop and let me sign in myself. Do not type them for me.

2. From the file browser, click the account menu in the top left and choose "Settings". Open the Security tab and scroll to "Personal access tokens". Click "Generate new token".

3. Name the token "Framelink MCP" and set an expiration. Then tick exactly these scopes:
   current_user:read
   file_comments:read
   file_comments:write
   file_content:read
   file_metadata:read
   file_versions:read
   library_assets:read
   library_content:read
   team_library_content:read
   file_dev_resources:read
   file_dev_resources:write

4. Click "Generate token", then stop. Figma shows the token once and I'll copy it myself — don't read it out of the page. Tell me you're waiting, and I'll paste it back to you.

5. Once I give you the token, add the MCP server to whichever harness you are running in right now. Look up that harness's own MCP configuration format and file location rather than guessing; if you aren't sure which harness you're in, ask me. The server is:

     command: npx
     args:    -y figma-developer-mcp --figma-api-key=YOUR-KEY --stdio

   Replace YOUR-KEY with the token I gave you.

   On Windows, npx is a batch file that most MCP clients can't launch directly. Use "cmd" as the command and put "/c", "npx" at the front of the args instead.

   Give the server the name Framelink_Figma_MCP. If a config file already has an entry for it, update that entry instead of adding a second one.

6. Reload your MCP servers (restart if that's what your harness needs) and confirm the Framelink tools are available. If they aren't, read the server's startup output and tell me what failed.

7. Tell me you're ready, and I'll send you a Figma link to build from.
</Prompt>

## 1. Grab your Figma access token

### Open your Figma account settings

From the home page in Figma, click your profile icon in the top left corner, then choose **Settings**.

<Frame>
  <img src="/images/quickstart/figma-open-settings.png" alt="The Figma profile menu open, with the Settings item highlighted" />
</Frame>

### Generate a new token

In the settings dialog, switch to the **Security** tab, scroll down to **Personal access tokens**, and click **Generate new token**.

<Frame>
  <img src="/images/quickstart/figma-generate-token.png" alt="The Security tab of Figma settings, with the Generate new token link highlighted" />
</Frame>

### Select the scopes the MCP needs

Give the token a name, set an expiration, then **check every scope shown below** before clicking <code>Generate&nbsp;token</code>. Figma tokens are scoped, and a token created with the defaults will not have what the MCP needs.

<Frame>
  <img src="/images/quickstart/figma-token-scopes.png" alt="The Figma token scope picker with current_user:read, file_comments:read, file_comments:write, file_content:read, file_metadata:read, file_versions:read, library_assets:read, library_content:read, team_library_content:read, file_dev_resources:read, and file_dev_resources:write all checked" />
</Frame>

If you need more detailed instructions, you can find them in [Figma's documentation on access tokens](https://help.figma.com/hc/en-us/articles/8085703771159-Manage-personal-access-tokens).

### Special Runtime Environments

<AccordionGroup>

<Accordion title="Windows">

On Windows, `npx` is a batch file (`npx.cmd`) and cannot be run directly by most MCP clients. Use `cmd` to run `npx` instead. In the JSON configuration above, replace `"command": "npx"` with `"command": "cmd"` and add `"/c", "npx",` to the beginning of the `args` array:

```json
{
  "mcpServers": {
    "Framelink_Figma_MCP": {
      "command": "cmd",
      "args": ["/c", "npx", "-y", "figma-developer-mcp", "--figma-api-key=YOUR-KEY", "--stdio"]
    }
  }
}
```

</Accordion>

<Accordion title="Using Bun or Deno instead of npx">

If you prefer an alternative runtime to Node.js, you can use Bun or Deno to run the MCP server. Use these in place of the `npx` command in your editor's config above.

#### Bun

```json
{
  "mcpServers": {
    "Framelink_Figma_MCP": {
      "command": "bunx",
      "args": ["-y", "figma-developer-mcp", "--figma-api-key=YOUR-KEY", "--stdio"]
    }
  }
}
```

#### Deno

```json
{
  "mcpServers": {
    "Framelink_Figma_MCP": {
      "command": "deno",
      "args": [
        "run",
        "--allow-env",
        "--allow-net",
        "npm:figma-developer-mcp",
        "--figma-api-key=YOUR-KEY",
        "--stdio"
      ]
    }
  }
}
```

</Accordion>

</AccordionGroup>

## 3. Implement your first design

After configuring your IDE, you'll be able to pull complete design data from any Figma file.

### Copy a link to a Figma frame or group

The MCP server compresses the data it receives from the Figma API by almost 90%. Even still, complex designs can overwhelm AI agents with too much information.

You can try to get your editor to implement a whole design for you, but for the most consistent results, work on one section at a time.

To do that, **right click on the frame or group you'd like to implement, then select <code>Copy/Paste&nbsp;as</code> and choose <code>Copy&nbsp;link&nbsp;to&nbsp;selection</code>.**

<Frame>
  <img src="/images/quickstart/figma-copy-link.png" alt="The Figma right-click menu with Copy/Paste as, then Copy link to selection" />
</Frame>

### Paste the link into your editor

Once you have a link to the Figma frame or group, you can make a request to your editor's AI agent.

A request as simple as "Implement this Figma frame" along with the link should be enough to get the agent to call the MCP's `get_figma_data` function, but [more context is often helpful in getting the best results](/best-practices).

<Frame>
  <img src="/images/quickstart/ide-paste-link.png" alt="A Figma selection link pasted into an editor chat prompt" />
</Frame>

### Get your design

After submitting your request, your coding agent will get to work. It should call the MCP's `get_figma_data` function with the link you provided. Using the information returned from this function, your agent will generate a design.

<Frame>
  <img src="/images/quickstart/ide-get-result.png" alt="A coding agent calling the MCP get_figma_data tool and writing the resulting markup" />
</Frame>

As you can see above, the agent decided to name the classes `frame-###` since the Figma frames used in this example used Figma's default naming. Since this was a very simple design without much context about the intended use of the element, the agent just went with a literal interpretation of the frame's contents.

The design, however, is complete and functional.

<Frame>
  <img src="/images/quickstart/chrome-final-product.png" alt="The implemented design rendered in a browser" />
</Frame>
