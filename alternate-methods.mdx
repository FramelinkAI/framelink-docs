The recommended way to run the MCP is the stdio setup in the [Quickstart guide](/quickstart), where your client launches the server for you. This guide covers other ways to run it.

## HTTP server

Without the `--stdio` flag, the server runs as a standalone HTTP server that your client connects to by URL. This is useful when your client can't launch local commands, or when several clients should share one server.

### Start the server

```bash
npx figma-developer-mcp --figma-api-key=YOUR-KEY
```

The server prints its configuration, then the address to connect to:

```text
Initializing Figma MCP Server in HTTP mode on 127.0.0.1:3333...
HTTP server listening on port 3333
StreamableHTTP endpoint available at http://127.0.0.1:3333/mcp
StreamableHTTP endpoint available at http://127.0.0.1:3333/sse (backward compat)
```

It listens on `127.0.0.1:3333` by default. Use `--port` and `--host` to change that; see [Configuration](/configuration#port).

### Connect your client

Point your client at the `/mcp` endpoint. Most clients that support remote servers take a `url` in their MCP config:

```json
{
  "mcpServers": {
    "Framelink_Figma_MCP": {
      "url": "http://localhost:3333/mcp"
    }
  }
}
```

In Claude Code:

```bash
claude mcp add --transport http Framelink_Figma_MCP http://localhost:3333/mcp
```

The server speaks Streamable HTTP. `/sse` serves the same transport, so older configs that point at `/sse` keep working, but new configs should use `/mcp`.

The Figma token is set when you start the server, not in the client config. Clients can instead send their own token on each request with the `X-Figma-Token` header; see [Per-request token](/configuration#per-request-token).

## Running from source

1. Clone the [repository](https://github.com/GLips/Figma-Context-MCP).
2. Install dependencies with `pnpm install`.
3. Copy `.env.example` to `.env` and set `FIGMA_API_KEY` to your [Figma access token](https://help.figma.com/hc/en-us/articles/8085703771159-Manage-personal-access-tokens). Other settings go in `.env` too; see [Environment variables](/configuration#environment-variables).
4. Run `pnpm dev`. It rebuilds on every change and restarts the HTTP server. Use `pnpm dev:cli` to run in stdio mode instead.
5. Connect your client to `http://localhost:3333/mcp`, as shown above.

## Inspect responses

To trigger tool calls and inspect responses by hand, run `pnpm inspect` from the repository. It launches the [MCP Inspector](https://github.com/modelcontextprotocol/inspector) web UI.

```bash
pnpm inspect
```
