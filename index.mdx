Framelink MCP for Figma is a [Model Context Protocol](https://modelcontextprotocol.io/introduction) server that connects your coding agent to Figma. Paste a link to a Figma file, frame, or group into your agent's chat, ask it to implement the design, and the agent fetches the design data it needs to write the code.

## What it does

The server calls the Figma API on your behalf and gives your agent two tools:

- **`get_figma_data`** returns the design as structured data: the layer hierarchy, layout (including auto layout and grid), styling such as colors, gradients, strokes, and effects, text content and styles, and component information.
- **`download_figma_images`** saves the PNG, SVG, and GIF assets a design uses into your project.

The raw Figma API response is large and full of detail a model doesn't need. Before handing it to your agent, the server simplifies and translates it so only the relevant layout and styling information remains. Less noise in context makes the agent more accurate.

## Why not just a screenshot?

A screenshot forces the agent to guess spacing, colors, font sizes, and how elements are grouped. Structured data gives it the exact values and the real structure of the design, so the first pass of code lands much closer to the design.

## What it isn't

Framelink MCP for Figma reads designs. It doesn't write code itself — your coding agent does that, using the data the server provides. It works with any agent or editor that supports MCP servers.
